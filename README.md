# Movie-Rating-and-Audience-Preference-Analysis

EDA on MovieLens dataset — uncovering audience preferences through rating patterns, genre trends & viewing behavior. 100,836 ratings | 9,724 movies | 610 users | Python, Pandas, Matplotlib

## Project Overview

This project focuses on analyzing the MovieLens dataset to understand audience rating behaviour and explore patterns associated with genre preferences, release era trends, and user engagement. Python and data visualization techniques are used to clean, analyze, and present the data.

## Objectives

- Analyze the MovieLens movie ratings dataset.
- Identify important factors that influence movie ratings.
- Explore patterns associated with genre preferences, release decade, and audience behavior.
- Perform data cleaning and preprocessing on raw rating data.
- Visualize rating distributions, genre trends, and temporal patterns.
- Develop analytical insights to support movie recommendation strategies.

## Datasets

- MovieLens Ratings Dataset (100,836 ratings by 610 users across 9,724 movies)
- Raw Movie Ratings Data (unprocessed, with missing values and duplicates)
- Cleaned Movie Ratings Data (processed, feature-engineered, ready for analysis)
